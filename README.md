Heaven Hotel Booking

Description:
Heaven Hotel Booking is a web application built with HTML, CSS, and PHP, connected to SQL for managing hotel reservations. Users can browse available rooms, make bookings, and view reservation details through a simple and responsive interface.

Features

Browse available hotel rooms

Make room reservations

View and manage existing bookings

Responsive design for desktop and mobile

Technologies Used

HTML & CSS – Frontend structure and styling

PHP – Server-side scripting and logic

SQL – Database for storing room and reservation data
